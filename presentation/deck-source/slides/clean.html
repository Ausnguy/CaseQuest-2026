AUSTIN (about 30 sec) The data we were given was messy. Most of the sensor file was in there twice. Machine IDs were scrambled, some temperatures were in Fahrenheit, and some totals were missing. We cleaned all of it and logged every change. Where a number was missing, we either rebuilt it with the case’s own formula or left it blank. We never guessed. Then we proved it: 39 automated checks, including that every single outage adds up exactly to the monthly production numbers. One command rebuilds everything from the raw file. Our limits: the data is synthetic, readings are once a day, and there are only six sites.
