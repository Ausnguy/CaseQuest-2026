# CaseQuest 2026

Team repository for **CaseQuest 2026**, a case competition sponsored by **ConocoPhillips** and hosted by the University of Houston's MISSO, FITP, and CougarCS organizations.

## Overview

Our team will analyze a real-world oil and gas business challenge, develop a data-driven solution, and present our findings and recommendations.

**Event Dates:** October 23–24, 2026

**Status:** Awaiting case release.

## Project Structure

The repository structure, technologies, and implementation will be determined after the official case is released.

Potential components include:
- Data exploration and analysis
- Data processing and visualization
- Business recommendations
- Technical implementation
- Final presentation and documentation

## Collaboration

Team members will collaborate using GitHub for version control and Google Drive for shared documents and presentation materials.

## Getting Started

Setup instructions and project requirements will be added after the competition kickoff.
